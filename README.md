# スーパーマルバツゲーム — スーパー三目並べ：9 つの盤で 3 つ並べる

9 つの三目並べを 3×3 に並べた「スーパー三目並べ」（英語では Ultimate Tic-Tac-Toe）。打ったマスの位置で相手が次に打つ盤が決まるので、先を読んで送り込む。1 台の端末でふたり対戦。

## 🔗 リンク

- 遊ぶ: https://t-of.github.io/super-marubatsu/
- 制作: [T.OF...](https://t-of.github.io/)

## 遊び方

9 つの三目並べ（小盤）を 3×3 に並べた盤（大盤）で遊びます。× が先攻。

1. 好きなマスに打つと、そのマスの位置（0〜8 の 3×3）が、次の人が打つ小盤を決めます。右上に打てば、相手は右上の小盤に打ちます。
2. 小盤で先に 3 つ並べると、その小盤を取れます。**決着した小盤（取られた・引き分け）には、空きマスがあっても打てません。**
3. 送られた小盤がすでに決着しているときは「フリーターン」。決着していない小盤ならどこにでも打てます。
4. 取った小盤で大盤に 3 つ並べたら勝ち。どちらも並べられないまま打てるマスがなくなったら引き分け。

操作: マスをタップ（クリック）して打つ。「1 手戻す」（PC は Z・Backspace）、「メニュー」（PC は Esc）。設定の「確定タップ」をオンにすると、1 回目のタップで薄く印を置き、同じマスをもう一度タップして確定します。

日本語で一般に「スーパーマルバツゲーム」「スーパー○×ゲーム」と呼ばれる遊びで、英語では **Ultimate Tic-Tac-Toe** と呼ばれます。

## アプリとして入れる（PWA）

- iPhone / iPad: Safari で開き、共有 → 「ホーム画面に追加」
- Android / PC の Chrome・Edge: 画面の「アプリにする」ボタン、またはアドレスバーのインストールボタン

## 開発

ビルド不要。フォルダをそのまま静的サーバで開く。

```sh
python3 -m http.server 8000   # → http://localhost:8000/
node tools/test.js            # ルールのテスト
```

盤は手番ごとに小盤を 9 ビットの整数で持つ（`js/game.js`）。ブラウザでは `<script src="./js/game.js">` のグローバル `SMGame`、node では `require('./js/game.js')` から同じファイルを使う。第 2 版（AI）でもこの持ち方をそのまま使う。

## AI（第 2 版）

自分どうしの対局（`node tools/train.js`、81 世代、`.train/run1`）で NN を育て、最良の世代（71）を `ai/net.json` に書き出している。強さは `node tools/arena.js --work <世代の入ったフォルダ> --games 100 --matchGames 400` で測った。

Elo の表（M1k = 素の MCTS 1,000 回 = 0。M10k・M100k も素の MCTS）:

| 相手 | Elo |
|---|---|
| M100k（素の MCTS 10 万回） | 621 |
| M10k（素の MCTS 1 万回） | 317 |
| 最良ネット（NN + MCTS 200 回、学習中の物差し） | 157 |
| M1k（素の MCTS 1,000 回） | 0 |

「最強」の合格判定（最良ネット + MCTS と、素の MCTS を同じ 1 手 1 秒で 400 局）: NN 側の勝率 51.5%。**90% に届かず不合格**。ただしわずかに勝ち越しているので、段階 5「最強」には仕様どおり勝ったほう（NN 側）を使う。先手の勝率は 54.5%。

段階ごとの設定は、最良ネットに時間を多く・少なく与えて素の MCTS 2 万回（段階 3「つよい」、Elo 目安 410）と当てて決めた:

| 段階 | 中身 | 対 M20k の勝率 | Elo 目安 |
|---|---|---|---|
| 3 つよい | 素の MCTS 2 万回 | - | 410 |
| 4 達人 | NN + MCTS、1 手 500ms まで | 64.4% | 513 |
| 5 最強 | NN + MCTS、1 手 2000ms まで | 75.0% | 601 |

段階 4 は当初「NN + MCTS 100 回」だったが、これは段階 3 より弱かった（測って分かった）。NN は読む回数がある程度ないと強くならないため、回数ではなく時間で決める形に変えた。
net が読み込めないとき（`ai/net.json` が読めない・壊れている）は、段階 4・5 とも素の MCTS の時間ぎめ版（`js/ai-worker.js` の `NO_NET_FALLBACK`）で代える。
